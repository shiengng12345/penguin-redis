## 这个目录的纪律

- **绝不进索引。** `crates/pr-intelligence/src/phrases.rs` 里放的是 canonical 与所有**已作废**的
  语料；本目录一句都不在里面，由 `the_index_contains_nothing_from_the_live_independent_corpus`
  逐条断言。它上线当天就抓到三句——live 语料与一份已作废语料逐字撞了三句，原作者改写了它们。
  改写前 83.7 / 91.0，改写后 83.2 / 90.5：那 0.5 个百分点是三道答案已经在索引里的题。
- **绝不用它的 miss 改任何东西。** 一旦用了，它就按 §16.4 移进 `../heldout-independent-*-void/`，
  并在那里连同数字一起留档（`../heldout-independent-v1-void/` 就是这么来的）。
- **撞句由原作者改写，不由实现者改写。** 实现者动手就等于把自己的措辞塞进了 held-out 集。

## 残余的不独立性

八位撰写人与实现者都是语言模型，共享预训练分布，所以这里的「独立」弱于一位从未接触过这个项目的
人类写出来的语料。这一点写在这里而不是不提。真正的人类语料到达时，按同一套流程测一次即可，
这两轮会成为对照。
