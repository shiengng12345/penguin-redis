# ADR-026 · Reedline 仅作编辑状态引擎；终端所有权归 `pr-terminal`；SPIKE-001 决定是否回退自有 LineBuffer

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §14.5、§31.1、R03
- **Phase 0 验证项**：V-C01、V-C02、V-J04

## Context

Reedline 的 `Completer` 是同步 API、菜单内建、external printer 会写 scrollback，不满足 §14 的自动弹出 / 异步 revision / Enter 归属契约（三方评审一致）。

## Decision

允许复用 `LineBuffer`/`Editor`/`History`/`Hinter`/`Completer` 的 span 结构；不复用 `read_line` 事件循环、内建 menu、printer、raw mode 管理。SPIKE-001（V-C01）是 E2 门禁：(a) 外部 `TextEdit` 不丢字节；(b) 接受候选为单事务；(c) 与 `pr-terminal` 组合通过 ASSIST-020~028/062~064。任一不满足 → **回退方案已命名**：`pr-repl` 自有 grapheme-aware LineBuffer，复用 Reedline history 文件格式，跑同一套测试。

## Consequences

本 ADR 的决策框架已接受；SPIKE-001 结论写入 ADR-026 的「结果」小节（V-J04）。
