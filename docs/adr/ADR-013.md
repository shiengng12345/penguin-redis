# ADR-013 · `--raw`、`--json`、`--output typed-json|ndjson|resp`、`--bytes` 是独立契约，互斥

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §18.1~18.4、R13、R17、R40、R47、PIPE-01~04
- **Phase 0 验证项**：V-B06、V-E04

## Context

脚本需要稳定的机器契约；把 pretty 偏好泄漏进 JSON schema 会破坏下游。

## Decision

TTY 默认 pretty；非 TTY 默认 raw；`--json` 按 baseline（默认 RESP3，`-2` 不自造 map），投影表 v1 固定（§18.3）；typed-json 版本化、binary base64、map 为 entries；ndjson 每事件一行；`--output resp` 是规范化再编码（不是 wire 抓包）；`--bytes` 单 blob 原值。flags 冲突报错。push 帧不进 one-shot stdout。stdout 只放数据，其余进 stderr。

## Consequences

每种输出有 differential/fixture；`--raw`/`--bytes`/`--output resp` 直写 TTY 给警告。

## 结果 / 验证记录

**PASS**（2026-09-16，V-B06、V-E04）。

`crates/pr-application/tests/json_projection.rs` 29 个测试把 §18.3 的投影表逐行变成断言，`compatibility/manifest.toml` 的 `[json_projection]` 段记录了与 `redis-cli` 的 6 处实测差异与 8 处一致——差异被写下来，而不是被抹平。`crates/pr-application/src/output.rs` 与 `tests/push_output.rs` 25 个测试守住互斥与通道纪律：flags 冲突报错而非后者赢，push 帧不进 one-shot 的 stdout，stdout 只放数据。V-A02 在这里抓到过真实缺陷：`--json` 曾输出 `"..."` 这种**根本不是合法 JSON**的东西，`jq` 读不了；错误退出码曾给 0，于是 shell 的 `&&` 链会继续往下跑。
