# ADR-024 · 审批令牌绑定 canonical argv 字节哈希 + 完整 `TrustIdentity` + epoch + 有效期；摘要只用于显示

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §23.2、§29.4、R02、R12
- **Phase 0 验证项**：V-D03、V-D08

## Context

「命令与参数摘要」可被脱敏/截断/转义/Unicode 规范化碰撞，用户批准的与 kernel 执行的可能不是同一条命令（评审 BLOCKER）。

## Decision

`request_hash = blake3(len(argv) ‖ Σ(len(arg_i) ‖ arg_i))`；`plan_hash` 用于批量；kernel 执行前重算比对，任一字节不同即拒绝（退出码 5）；令牌不可跨 profile/DB/identity/TrustIdentity；`:approval show --bytes` 展开完整 argv。策略型批准只覆盖只读 + key 模式 + 次数上限，写类一律人签。

## Consequences

SEC-10、ASSIST-080；MCP `execute_approved_plan` 校验 `plan_hash`。
