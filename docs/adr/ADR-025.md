# ADR-025 · `--pipe` 原始协议输入逐帧解析并经过同一 catalog / policy；agent origin 默认不可用

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §18.5、R01
- **Phase 0 验证项**：V-B03

## Context

把 `--pipe` 当 opaque stream 直接转发，就是一条完整的策略绕过通道（评审 BLOCKER）。

## Decision

stdin RESP 用 `pr-protocol` decoder 逐帧解析为 `CommandRequest`；非 array-of-bulk / 截断 / 超长 → fail-closed 退出码 2 报帧序号；每帧 effects 由本地 catalog 决定，prod deny 写帧即停（5）；approval-required 帧在 pipe 中视为 deny，除非事先 `--plan-from-pipe` 生成并人签的 plan；背压有界；断线未确认帧标 `UnknownAfterSend`；`--compat` 不影响解析与策略。

## Consequences

SEC-09、PIPE-08；§28.4 特殊模式表中 `--pipe` 的行。
