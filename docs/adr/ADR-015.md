# ADR-015 · CLI 与 TUI 的自动建议共用同一本地 Command Intelligence；LLM 不是依赖

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §10、§11.1、REQ-15~20、ASSIST-001/002
- **Phase 0 验证项**：V-F01、V-F04、V-F09

## Context

「记不住命令」是核心痛点，但用 LLM 逐字生成会带来隐私、延迟与不确定性；两套 grammar 会漂移。

## Decision

`pr-intelligence` 是纯本地库：输出 Suggestions/SignatureHelp/Diagnostics/Documentation/ProposedAction，不持有可执行 client。CLI、TUI、离线 Learn、shell completion、未来 Studio 共用。默认 Assisted 模式自动下拉（75 ms debounce）。AI 是可选补充，不进按键路径。

## Consequences

catalog 编译管线（V-F01）与 §11.7 语法复杂度全表是必需；密度模式 assisted/minimal/manual/off。

## 结果 / 验证记录

**PASS**（2026-09-16，V-F01、V-F04、V-F09）。

`pr-intelligence` 不依赖任何 transport crate，因此「不持有可执行 client」是编译期事实而不是纪律。catalog 来自 digest 钉住的快照（redis 8.0.6 / valkey 8.1.10），38 + 19 个测试；grammar 表按 §11.7 十一行逐行断言（19 tests）。V-F09 度量了这条 ADR 的代价：assistance 开启相对关闭的 RSS 差 **8.53 MiB**，在 12 MiB 预算内。LLM 不在按键路径上——V-F10 的零发送测试同时也是零联网测试。
