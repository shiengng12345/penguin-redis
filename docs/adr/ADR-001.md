# ADR-001 · 产品名 `Penguin Redis`，可执行文件 `prc`，profile 前缀 `@`

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §1.2 REQ-01/03、§3.1、§3.2
- **Phase 0 验证项**：V-B07

## Context

产品名需完整可识别，但每天要敲几十次的命令必须短。连接需要按名字复用而不是重复复制 URL。

## Decision

包名 `penguin-redis`；可执行文件固定为 `prc`；已保存连接以 `@name` 引用（`prc @dev`）。安装器不得覆盖用户现有 `prc`，不得自动 alias `redis-cli`。

## Consequences

所有文档、帮助、错误信息使用 `prc`；`@` 在命令行第一个非 flag 位置有保留含义，进入 `COMMAND` 区后 `@xxx` 是普通 value（§3.2）。

## 结果 / 验证记录

**PASS**（2026-09-16，V-B07）。

可执行文件名、`@name` 前缀与 `:` 命名空间三者一起由 `crates/prc/src/args.rs` 的 17 个测试守住：`@` 只在**第一个位置参数**上是 profile 引用，出现在别处是普通字节（一个 key 完全可以叫 `@dev`）；`prc @dev` 与 `prc -h host` 互斥并报错而不是让其中一个悄悄赢。安装器的两条禁令（不覆盖已存在的 `prc`、不自动 alias `redis-cli`）属于打包阶段，Phase 0 未产出安装器，因此写进 Phase 1 的发布门禁而不是在这里声称已验证。
