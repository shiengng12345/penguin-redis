# ADR-011 · 兼容性只对固定 baseline 的具体版本声称，不做全称承诺

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §3.4、§20.3、§20.4、R29
- **Phase 0 验证项**：V-A05、V-I01、V-I02、V-A02

## Context

「100% compatible」「所有版本更快」无法验证；`latest` 会漂移。

## Decision

`compatibility/manifest.toml` 固定 image digest、`redis-cli` tag、RESP 模式、拓扑、OS/terminal；只有实际跑过的版本标 verified，其余 `unknown`。初始矩阵：Redis 7.2/7.4/8.0、Valkey 8.0/8.1、`redis-cli` 7.4.x、Redis Stack 模块各一版、一个受限 ACL 云 fixture。`--compat=redis-cli` 按声明 baseline 调整默认，不是安全后门。

## Consequences

CI 用 pinned digest；前沿检测另设非阻断任务；Valkey 与 Redis 在 catalog 中双分支。
