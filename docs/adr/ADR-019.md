# ADR-019 · Hash field 发现避免隐式抓取 value；不支持 `HSCAN NOVALUES` 的目标明确降级

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §12.2、R44 引用、ASSIST-039/040
- **Phase 0 验证项**：V-F07

## Context

「只读字段名」实际抓整份敏感 Hash 是隐私违规；HKEYS/HGETALL 不是补全捷径。

## Decision

field 候选默认来自保留结果索引；远端补充只用 `HSCAN … NOVALUES`（7.4+）；旧目标自动 field completion 停用，仅在用户明确允许接收值后才用带值 HSCAN 并尽早丢弃 value；不为每个候选发 TYPE。

## Consequences

capability 探测决定入口是否存在；ASSIST-039/040。

## 结果 / 验证记录

**PASS**（2026-09-16，V-F07）。

`crates/pr-intelligence/src/discovery.rs` 与 `tests/discovery.rs`（19 tests）、`tests/discovery_live.rs`（5 tests，10⁶ key + 真实 ACL）：field 候选默认来自保留结果索引；远端补充只用 `HSCAN … NOVALUES`；目标不支持时自动 field completion **停用**而不是退回带值 HSCAN——后者会把用户没要的 value 拉过网络，而这正是本 ADR 的标题。本项在实测中把默认扫描上限从 50 调到 200（[ADR-033](ADR-033.md)），因为 50 在 10⁶ key 上仍然空手而归；调的是预算，不是规则。
