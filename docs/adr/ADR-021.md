# ADR-021 · 执行结果模型分四个正交维度：delivery / reply / effects / render

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §19.2、§19.6、§22.3、R30、R42
- **Phase 0 验证项**：V-B04

## Context

一个 enum 把「网络送达」「服务器回复」「副作用是否发生」「本地渲染」混在一起，导致 server error 被误当无副作用、渲染失败被误当未执行。

## Decision

`ExecutionOutcome { delivery, reply, effects: EffectsCertainty, render }`；`Partial` 用于 EXEC/pipe/批量；退出码与 typed `outcome` 由四维度确定性映射（含 Ctrl+C 优先级：任何 UnknownAfterSend → 6 优先于 130）。

## Consequences

v2.0 的过渡 enum 已删除；映射表是 fixture。

## 结果 / 验证记录

**PASS**（2026-09-16，V-B04）。

`crates/pr-protocol/tests/outcome_matrix.rs` 12 个测试把四个维度的组合映射到退出码，包括那条容易写反的优先级：任何 `UnknownAfterSend` 的 6 **优先于** Ctrl+C 的 130。理由在测试注释里：用户按 Ctrl+C 想知道的是「我按下去之前那条写命令到底发生了没有」，用 130 盖住 6 就是把这个问题的答案删掉。`Partial` 覆盖 EXEC / pipe / 批量三种「一半成功」的形状。
