# ADR-012 · Result Context：本地 inspect 与重新查询是两个不同动作

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §5.3、§10.11、UX-09、UX-10
- **Phase 0 验证项**：V-E03、V-F06

## Context

用户查看已有结果时不应触发新读取；但旧结果被淘汰后也不能假装还在。

## Decision

每次执行产生 `ResultId`（绑 profile/endpoint/DB/identity epoch/命令/时间/保留范围）。`:view`/`:copy`/`:inspect --field` 只读保留结果、0 请求；`:refresh`/`:inspect --key` 才发请求。被淘汰显示 `not retained` 并提供明确重读入口。field 补全从保留结果的名称索引读取。

## Consequences

作用域失效事件（切连接、SELECT、AUTH、重连）必须处理；结果来源始终显示。
