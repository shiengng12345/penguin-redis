# ADR-020 · Find / Guide / Learn / 单位助手 / 错误帮助默认零联网；模板与建议只插入，永不自动执行

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §13、§14.10、§12.3
- **Phase 0 验证项**：V-F10、V-F07、V-F08

## Context

帮助功能若偷发命令（或把 `清 cache` 直接变 FLUSHDB）会把「建议」变成「代操作」。

## Decision

零发送不变量：浏览、选中、预览、解释、换主题、接受建议、填 Guide 在断网下测试为 0 条业务命令；Guide 只插入 argv 预览；`5m` 只在用户接受后替换为 `300`；错误帮助解释与修复分离，不自动重发/DEL/换命令。远端 discovery 是独立 action（F6/`:complete`）带计划预览与预算。

## Consequences

transport spy 测试常驻；ASSIST-020/037/050~058/070。

## 结果 / 验证记录

**PASS**（2026-09-16，V-F10、V-F07；V-F08 的 recall 指标另见 [ADR-034](ADR-034.md)）。

零发送不变量由 `crates/pr-intelligence/tests/zero_send.rs` 11 个测试在断网条件下证明为 0 条业务命令。Guide 只插入 argv 预览，`5m` 只在用户接受后才变成 `300`，错误帮助把解释与修复分开、从不自动重发 / DEL / 换命令。远端 discovery 是独立 action，带计划预览与预算（V-F07）。本 ADR 关联的 V-F08 用途搜索本身零联网已成立，未成立的是**独立 held-out recall 指标**，原因与解阻条件记在 ADR-034。
