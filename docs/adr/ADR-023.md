# ADR-023 · `prc` 自身许可与 catalog 再分发结论（Phase 0 / V-I03 交付）

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §35.5、R29
- **Phase 0 验证项**：V-I03

## Context

Redis 7.4 起为 RSALv2/SSPL、8.0 起加 AGPLv3；其 `commands/*.json` 与文档许可需单独确认；Valkey 为 BSD-3。把上游 catalog 打进二进制有再分发风险。

## Decision

### 一、catalog 再分发

每个 upstream snapshot 登记来源、许可与三选一结论（可打包 / 用户运行时下载 / 本仓独立撰写）；**结论为空不得发布**；不可再分发部分由本仓按公开行为独立撰写并以 fixture 对照真实服务器。

V-I03 的审查结论（详见 `crates/pr-catalog/LICENSES.md`）把问题拆成了两半，因为快照里装的是两类性质不同的东西：

- **接口结构**（命令名、arity、flags、ACL 分类、key spec、参数树、`since`、`group`）→ **可打包**。它取自一个 digest-pinned 服务器的 `COMMAND DOCS` / `COMMAND` **运行时回复**，不是上游仓库里的源文件，任何人跑一次服务器都能重新得到同一份数据；`ci/check-catalog-snapshots.sh` 每次 CI 都在重做并要求逐字节一致。
- **上游撰写的散文**（`summary`、`complexity`，占原始回复 16%）→ **本仓独立撰写**。归一化阶段直接丢弃，`snapshot.rs` 的 schema 里没有这两个字段；因为那些 struct 是 `deny_unknown_fields`，将来某次抓取若重新带上它们会**加载失败**，而不是悄悄分发没人审过许可的文本。

Redis 的 `src/commands/*.json` 与文档站（CC-BY-SA-4.0）**从未取用**。避开文档站是刻意的：CC-BY-SA 的 copyleft 会传染到我们自己写的说明。

### 二、`prc` 自身许可

**`MIT OR Apache-2.0`**（SPDX 表达式，双许可，使用者任选其一）。

理由：

- Rust 生态的事实标准。企业法务对这两个许可的审查是例行放行，对 AGPL 往往是明确禁止——一个开发者用的 CLI 工具被法务禁用，等于没人用。
- Apache-2.0 那一半带明确的专利授权与商标条款；MIT 那一半给需要极简条款的嵌入场景一条路。两者并存覆盖面最大。
- 与嵌入的 catalog 结论相容：宽松许可不会对随二进制分发的接口结构数据附加额外义务。

**代价，明说**：这不给 Penguin Studio 任何商业保护。任何人可以拿 `prc` 去做闭源分发，包括做一个与 Studio 竞争的产品。如果这一点比采用率更重要，该换成 AGPL-3.0 或双轨商业许可——但那是一个产品决策，不是工程决策。

**这个决定是可逆的，且刻意做成一处改动**：`Cargo.toml` 的 workspace `license` 字段加两个 LICENSE 文件。项目尚未发布任何二进制、未上 crates.io、未进任何包管理器，因此在 Phase 7 发布之前更换许可不需要征得任何外部同意。`crates/prc/tests/licence.rs` 断言它是一个真实的 SPDX 表达式而非占位符，换的时候会一并提醒。

## Consequences

`crates/pr-catalog/LICENSES.md`、`LICENSE-MIT`、`LICENSE-APACHE`、notices、SBOM；CAT-001。

`cargo deny check licenses` 对第三方依赖只允许宽松许可（见 `deny.toml`），与本项目的双许可一致。

## 结果 / 验证记录

**V-I03 → PASS**（2026-09-16）。证据：`crates/pr-catalog/LICENSES.md`（逐来源结论表，无空结论）、`crates/pr-catalog/tests/grammar_table.rs::the_snapshot_carries_interface_structure_and_no_upstream_prose`、`crates/prc/tests/licence.rs`。

审查过程改变了实现：快照原先携带 `summary` 与 `complexity` 两个字段，现已在归一化阶段移除，二进制里不再包含任何上游撰写的散文。快照体积因此从 343 KB 降到 286 KB。

**未做而必须记下的**：上述「接口结构 vs 散文」的划分是工程判断，不是法律意见。发布前需要一次人工法务确认，已列入 `LICENSES.md` 的待办表与发布门禁，不阻塞 Phase 1。
