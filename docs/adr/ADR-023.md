# ADR-023 · `prc` 自身许可与 catalog 再分发结论（Phase 0 / V-I03 交付）

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §35.5、R29
- **Phase 0 验证项**：V-I03

## Context

Redis 7.4 起为 RSALv2/SSPL、8.0 起加 AGPLv3；其 `commands/*.json` 与文档许可需单独确认；Valkey 为 BSD-3。把上游 catalog 打进二进制有再分发风险。

## Decision

每个 upstream snapshot 登记来源、commit、许可与三选一结论（可打包 / 用户运行时下载 / 本仓独立撰写）；结论为空不得发布；不可再分发部分由本仓按公开行为独立撰写并以 fixture 对照真实服务器。`prc` 自身许可：**待 V-I03 审查后在此 ADR 填入**（决策框架已接受；具体许可证名称是 V-I03 的输出）。

## Consequences

`pr-catalog/LICENSES.md`、notices、SBOM；CAT-001。
