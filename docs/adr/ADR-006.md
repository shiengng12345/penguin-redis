# ADR-006 · 原始命令不隐式附带元数据请求，也不自动换算法

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §5.1、§6.4、§19.1、§25.1、CMD-08
- **Phase 0 验证项**：V-F10、V-E05

## Context

「为了显示 TTL 顺手发一条 TTL」或「HGETALL 太大自动改 HSCAN」都会让用户无法预测客户端到底发了什么。

## Decision

用户输入的命令按原 argv 发送，不追加 `TYPE`/`TTL`/`INFO`/`MEMORY USAGE`；不替换为分页算法。增强读取（inspector、browser）是**明确的**另一入口并显示将发送的命令。renderer 无网络权限。

## Consequences

banner 只显示已知信息；空 HGETALL 不能说「确认存在的空 Hash」；补全的远端发现走独立 action（ADR-020）。
