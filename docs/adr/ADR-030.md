# ADR-030 · 本地签名 catalog / overlay 是 effects、危险性、审批等级与 key extraction 的唯一权威；远端 metadata 只补充 availability 与文档

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §11.2、§20.2、R19
- **Phase 0 验证项**：V-D07、V-F01

## Context

被污染或过时的 `COMMAND`/`COMMAND DOCS`/module metadata 可能把写命令标成只读；客户端策略不能被服务器内容操纵。

## Decision

覆盖方向单向：远端只能把 `unknown` 变成 `unknown (server reports …)`、把 `documented` 变成 `observed-supported/unsupported`；不能改 `writes_data`→read、不能降危险等级、不能放宽策略；远端文本进 SafeText 并标 `from server`；本地不存在的命令允许通用执行，effects 为 `unknown` 按未分类策略处理。

## Consequences

SEC-11、ASSIST-086；V-D07。
