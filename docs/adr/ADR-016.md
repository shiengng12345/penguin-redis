# ADR-016 · 接受候选只编辑输入缓冲区；菜单焦点与提交分离；Enter 永不「补全并发送」

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §10.8、§14.1、R28、ASSIST-020~028
- **Phase 0 验证项**：V-C01、V-C02

## Context

最危险的误操作是一次 Enter 同时接受建议并执行；ghost text 被当成已输入也同样危险。

## Decision

§14.1 状态表：菜单未聚焦时 Enter 只提交真实 buffer；菜单聚焦时 Enter 只接纳；接纳后关闭菜单且不因自动补空格重开；唯一候选不自动插入；接受是单个可撤销 edit 事务且校验 buffer revision 与 epoch。历史下一条由 Ctrl+N 保证可达。

## Consequences

需要自绘菜单与自有事件循环（ADR-026）；ASSIST-020~025、087 是 E2 门禁。
