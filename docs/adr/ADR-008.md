# ADR-008 · CLI / TUI / MCP / recipe / `--pipe` 全部经过同一 execution kernel 与 policy

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §19.1、§17.4、§18.5、§29.4、ASSIST-080
- **Phase 0 验证项**：V-B03、V-D08、V-C02

## Context

多入口各自连 Redis 会形成多套暗中不同的语义，也让策略可被绕过。

## Decision

所有请求构造为 `CommandRequest` 经 `pr-application` → policy/budget/approval → `pr-core` kernel。TUI 不自带连接逻辑；`--pipe` 逐帧解析后走同一路径（ADR-025）；MCP 工具面是受限包装。

## Consequences

任何新入口都需要 transport-spy 测试证明经过 kernel；差异测试覆盖入口而非仅命令。
