# ADR-009 · 有界解码与有界保留；落盘 spool 必须显式授权

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §24、§8.2、R31、PERF-01、PIPE-07
- **Phase 0 验证项**：V-B02、V-E03、V-H02、V-H03

## Context

读完整个响应再分页会在显示 20 行时吃掉整个响应的内存；用户不能接受静默截断后 exit 0。

## Decision

增量 RESP decoder 带最大嵌套/声明长度/aggregate 个数/总预算；result store 64 MiB 总量、16 MiB 单结果，淘汰标 `not retained`；spool 只在用户同意后写入私有权限、防 symlink 的路径；已知长度在首字节前询问，未知长度流式不中途询问，非 TTY 永不询问。

## Consequences

1 GiB synthetic blob 是常驻 benchmark；JSON 输出中途失败必须非零退出；订阅 ring buffer 记录淘汰数。

## 结果 / 验证记录

**PASS**（2026-09-16，V-B02、V-E03、V-H02、V-H03）。

四项预算各有归属。解码预算：`crates/pr-protocol/` 的嵌套 / 声明长度 / aggregate 个数 / 总量上限，316 样本逐字节喂入时每个上限都有触发用例。保留预算：`crates/pr-results/src/store.rs` 14 个测试，64 MiB 总量、16 MiB 单结果、淘汰标 `not retained` 而不是静默丢。流式：V-H02 证明 1 GiB 合成值与 512 MB 真实值都以 **64 KiB 峰值持有**通过，这正是「有界解码」的可度量形态。订阅：`crates/pr-results/src/subscription.rs` 12 个测试。spool 的显式授权与非 TTY 永不询问由 store 侧测试覆盖。
