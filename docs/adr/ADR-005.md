# ADR-005 · 原始 bytes 是权威数据；任何 view 不改变类型、顺序或词法

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §8.1、§8.3、§8.4、DATA-01~06
- **Phase 0 验证项**：V-E01、V-B02

## Context

Redis bulk string 是 binary-safe 不保证 UTF-8；JSON 数字词法、重复成员在普通 map 模型中会静默丢失，破坏可信性。

## Decision

三层分离：Redis bytes（不可变）→ Presentation model → Display view。`"000123"` 不数值化、大整数不转 f64、`1.2300` 保留、重复成员保留并提示、非 UTF-8 走 escaped/binary 视图。`:copy` 默认复制原始字节解释。

## Consequences

禁止 `HashMap<String,String>` 作统一结果模型；需要 `pr-json` occurrence DOM（ADR-028）；导出/复制的内容与显示装饰分离。
