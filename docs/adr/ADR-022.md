# ADR-022 · 单一 terminal coordinator；shell completion 与 REPL completion 是不同适配层

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §14.4、§14.9、R03
- **Phase 0 验证项**：V-C02、V-A01

## Context

Reedline、Ratatui、Tokio worker 同时读 stdin / 写 stdout 会乱序；zsh/bash 的补全浮层由 shell 决定，无法承诺一模一样。

## Decision

`pr-terminal` 唯一持有 crossterm 事件源与 painter；REPL 编辑器、下拉、异步通知、pager、TUI alternate screen 都经它；CLI 模式保留 scrollback、下拉只在 prompt 附近重绘。shell completion 提供 profile/flags/命令名/静态选项，默认不联网、不解锁 Keychain、不改 `.zshrc`。

## Consequences

Reedline 只作编辑引擎（ADR-026）；PTY 场景 ASSIST-062、UX-12。
