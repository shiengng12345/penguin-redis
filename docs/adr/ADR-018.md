# ADR-018 · Grammar / catalog ≠ server capability ≠ ACL 权限；三者分开显示

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §11.9、§20.2、ASSIST-034~036/078
- **Phase 0 验证项**：V-D07、V-F04

## Context

「命令在文档里」不代表服务器支持，更不代表当前用户有权；历史成功不证明今天允许。

## Decision

五个维度独立：Catalog（documented/unknown/deprecated）、Server support（observed-*/unknown）、Local policy（allowed/approval/denied）、Server ACL（unknown/observed-denied/checked-at）、Session。`ACL DRYRUN` 不进按键路径。未知不等于不支持；本地 deny 可解释但不可绕过。

## Consequences

候选每条带来源/能力状态标签；UI 文字标签不只靠颜色。
