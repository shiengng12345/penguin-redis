# ADR-028 · `pr-json` 是服务器业务 JSON 的唯一权威模型；重复成员以 occurrence 索引寻址；`serde_json` 只用于 Penguin 自有 schema

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §8.3、§8.5、§31.3、R06
- **Phase 0 验证项**：V-E01

## Context

§8.3 的无损规则（重复成员、数字词法、原顺序）不可能用 `serde_json::Value`/`Map` 满足；`RawValue` 只保原文片段无编辑语义（三方评审一致）。

## Decision

`JsonNode { span, kind, Number.lexeme, String.raw, Object.members: Vec<(key, node, occurrence)> }`；路径 `$.a#2`；存在重复成员时无 `#n` 的路径拒绝解析（`ambiguous member`）；编辑只重写目标 span；pretty 是视图操作不回写；`--json` 投影对重复成员的行为在 §18.3 表定义。

## Consequences

新增 crate `pr-json`（V-E01 / SPIKE-004）；Tree/editor/diff/Undo 只接受 occurrence 路径；JSON-05。
