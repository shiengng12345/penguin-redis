# ADR-002 · 原生 Redis 命令语义优先；本地增强操作使用 `:` 命名空间

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §3.5、§3.6、R18
- **Phase 0 验证项**：V-F03、V-B07

## Context

用户的 Redis muscle memory 是核心价值；本地功能（inspect/copy/find/guide）不能与服务器命令名冲突，也不能让用户分不清哪条会访问 Redis。

## Decision

任何不以 `:` 开头的输入按原始 argv 发送给 Redis（经 policy）；`:` 开头由本地 tokenizer 解析（§3.5）。提供 `:send -- CMD` 绕过本地名解析。官方 REPL 的 HELP/CONNECT/CLEAR/EXIT 等在 compatibility manifest 中逐项登记映射。

## Consequences

本地命令需要独立 grammar 与 fixture（V-F03）；`:` 命令表每条标注是否访问 Redis。

## 结果 / 验证记录

**PASS**（2026-09-16，V-F03、V-B07）。

`crates/pr-repl/` 26 个测试逐条验证分派规则：不以 `:` 开头的输入按原 argv 送出，本地 tokenizer 完全不参与解释；`:` 开头走本地 grammar，重复选项报错、零 shell 展开。`:send -- CMD` 的存在使「命令名恰好以 `:` 开头」不是死路。官方 REPL 动词的映射登记在 `compatibility/redis-cli-modes.toml`（20 modes），由 `crates/pr-application/tests/cli_modes.rs` 12 个测试对照 `redis-cli 8.0.6` 的真实 `--help` 输出。
