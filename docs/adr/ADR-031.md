# ADR-031 · `pr-protocol` 自研 codec 是唯一 kernel 协议边界；`redis-rs` 降为互操作测试对象

- **状态**：accepted
- **日期**：2026-09-16
- **依据**：v2.1 §31.2、§37.3、R27
- **Phase 0 验证项**：V-B01、V-J04

## Context

§31.2 给 `redis-rs` 定了六条门槛：保留需要的 RESP frame/type、大小与复制行为、push channel 预算、取消后读取行为、连接状态、重定向与内部重试。并预先写明了不达标时的分支——自建最小协议层，`redis-rs` 转为互操作测试对象。

SPIKE-002（V-B01）用 V-A03 的 316 个 fixture 对 `redis` 1.7.0 的公开低层 API 逐条实测。

## Decision

`pr-protocol` 的自研 codec 是 kernel 唯一的协议边界。`redis-rs` **只**作为互操作测试对象存在，以 `[dev-dependencies]` 形态锁在 `crates/pr-protocol`，由 `ci/check-redis-rs-is-dev-only.sh` 强制（`cargo tree -e no-dev` 解析真实链接图，所以直接引入或被间接拉入都会被抓到）。

不保留两套产品路径。§31.2 的原话是「最终单一执行内核不能有两套暗中不同的命令语义」。

## Consequences

- 协议层的正确性由我们自己负责；代价是 `crates/pr-protocol` 的 fuzz 与 fixture 覆盖必须持续（Phase 1 出口门禁：`pr-protocol` fuzz 24h 无 panic）。
- 换来的是 §31.2 全部六条都可实现：帧类型无损、budget 归我们、push 可计量、`Step::Incomplete` 与 `DecodeError::Protocol` 分开、消耗字节数已知因而连接可续用、重定向策略归 ADR-007 而不是一张我们改不动的表。
- `redis-rs` 的存在仍有价值：它是一个独立实现，两边对同一语料的分歧能同时暴露我们的 bug。19 个比对测试常驻 CI。

## 结果 / 验证记录

**PASS**（2026-09-16，V-B01 / SPIKE-002）。

§31.2 六条门槛：完整通过 0 条，部分通过 1 条。全语料 316 个 fixture 的比对结果已**冻结为断言**：

| 类别 | 数量 |
|---|---:|
| 一致 | 271 |
| 有损接受 | 10 |
| 未实现（全部是 RESP3 streamed 类型） | 28 |
| 过度接受（我们判协议错误，它当正常值） | 5 |
| 超出我方预算（它用自己的固定上限接受） | 2 |

关键不达标项：

1. **RESP3 streamed 类型完全未实现**——`$?` / `*?` / `%?` / `~?` / `;N` / `.` 不在 dispatch 表里。这是协议自己用来说「装不进内存」的机制。
2. **verbatim 与 blob error 走 `String::from_utf8_lossy`**——非 UTF-8 字节静默变成 `U+FFFD` 并返回 `Ok`。ADR-005 的存在就是为了防这个。
3. **double 丢词法**（`,1.2300` → `1.23`，`,1e999` → `inf` 且 `Ok`），违反 §18.3。
4. **三种 null 拼写塌缩成一个 `Nil`**，`--output resp` 无法忠实回写。
5. **没有 budget，也没有地方放**——`$1073741824` 与「还没收完」不可分（§24.4）。
6. **取消后连接不可复用**——`Parser::parse_value` 收阻塞 `Read`，遇到 `WouldBlock` 返回错误且不报告已消耗字节数；`parse_redis_value` 同样不报告消耗量，缓冲里有两帧时第二帧无从定位。
7. **重试策略不可观测也不可覆盖**——`retry_method()` 是 `pub(crate)`，与 ADR-007「写命令不盲目重试」直接冲突。
8. **过度接受 5 例**：`$-5` / `*-5` / `~-5` → `Nil`，`:+1` → `Int(1)`，`(12a` → 不校验。一个看起来像值的协议违规比一个看起来像错误的更糟。

如实记录 `redis-rs` 做对的地方：map 顺序与重复 key 保留、big number 保留数字串、attribute 在此层保留、bulk string 二进制安全、**截断与畸形可区分**（IO 类 vs parse 类错误）。

证据：`docs/spikes/SPIKE-002.md`、`crates/pr-protocol/tests/spike_002_redis_rs.rs`（19 tests）、`ci/check-redis-rs-is-dev-only.sh`。
